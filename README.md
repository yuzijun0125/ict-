# ICT 大赛项目 · 眼底疾病可进化决策智能体

第十一届华为 ICT 大赛创新赛 **赛题3**参赛项目仓库。

> **赛题**：基于华为 ModelEngine / Nexent，打造可进化决策智能体
> **研究方向**：眼科 · 眼底疾病
> **项目定位**：辅助决策支持系统（不提供疾病诊断与治疗处方，最终医疗决策由执业医师作出）

---

## 项目一句话

把"该不该转诊、多久复查、转到哪一级"这个基层眼科最常见、最容易做错的决策，交给一个能从复核结果中不断自我修正的智能体。

## 核心设计

### 决策链

```
输入（眼底影像 + 临床数据）
  → 图像质控 → 特征描述提取
  → 知识库检索（指南依据）
  → 记忆检索（相似案例与个体偏好）
  → 规则推理（风险分级 + 急症升级）
  → 决策输出（转诊建议 / 紧急度 / 随访间隔 / 依据 / 免责声明）
```

### 进化闭环

```
决策输出 → 临床反馈（复核结果 / 医生采纳与否 / 复查进展）
   → 记忆沉淀 + 知识库修正
   → 评估器计算指标（敏感度 / 特异度 / Kappa）
   → 版本迭代 v1 → v2（指标提升可量化）
```

### 范围边界

| 做 | 不做 |
|---|---|
| 转诊必要性判断 | 疾病确诊 |
| 紧急程度分级 | 治疗方案制定 |
| 随访间隔建议 | 用药与剂量建议 |
| 分级诊疗路径建议 | 手术指征判定 |

## 合规声明

- 本项目为**辅助决策支持**，不替代医师执业行为

- 输出内容附免责声明与依据来源
- 涉及真实临床数据时须通过伦理审查（IRB）并完成去标识化
