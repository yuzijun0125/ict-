# ICT 大赛项目 · 眼底影像辅助诊断"可进化"智能体

第十一届华为 ICT 大赛创新赛 **赛题3**参赛项目仓库。

> **赛题**：基于华为 ModelEngine / Nexent，打造可进化决策智能体
> **研究方向**：眼科 · 眼底疾病
> **核心输入**：患者眼底影像（彩色眼底照相为主，可选 OCT/OCTA）+ 临床信息
> **核心输出**：结构化影像征象描述 + 疑似疾病排序 + 判断依据 + 分级建议

---

## 项目一句话

**给医生看一张眼底片子，智能体输出"看到了什么 + 可能是什么 + 依据是什么"，由医生做出最终诊断。**

医生每次的采纳或修正，都会沉淀为智能体的经验，使下一次判断更接近医生的标准。

---

## 产品形态

```
        ┌─────────────────────────────────────────┐
        │           医生（最终决策者）              │
        └───────────────▲─────────────────────────┘
                        │ 复核 / 确认 / 修正
        ┌───────────────┴─────────────────────────┐
患者眼底影像 ──►│    Nexent 眼底辅助诊断智能体            │
（CFP/OCT/OCTA）│  ① 影像质控   ② 征象描述               │
       +        │  ③ 疑似疾病排序  ④ 分级建议             │
   临床信息      │  ⑤ 判断依据（可溯源）  ⑥ 免责声明        │
                └─────────────────────────────────────────┘
                        │
                        ▼
              医生修正结果 → 反馈沉淀 → 智能体进化
```

---

## 三条铁律（合规与可信基础）

1. **只给"辅助意见"，不下"最终诊断"** —— 输出使用"考虑/疑似/需结合临床"，最终诊断由执业医师作出
2. **必须给依据** —— 每条意见附征象依据与指南出处，可溯源、可复核
3. **医生必须在环** —— 医生确认/修正的结果是唯一"金标准"，也是进化的唯一反馈源

> ⚠️ **合规声明**：本项目定位为**科研与竞赛演示用辅助诊断工具**，非医疗器械，不用于临床独立诊断，未经 NMPA 注册不得用于临床诊疗决策。

---

## 可进化机制

```
① 智能体输出辅助意见
        ↓
② 医生复核：采纳 / 修正 / 否决（附原因）
        ↓
③ 差异分析：建议 vs 医生结论
        ↓
④ 记忆沉淀（个案经验） + ⑤ 知识库修正（规则完善）
        ↓
⑥ 评估：与医生金标准对比（准确率 / Kappa 一致性）
        ↓
⑦ 版本迭代 v1 → v2（指标提升可量化）
```

**进化的三类证据**：行为证据（反馈后结论改善）、指标证据（准确率/Kappa 提升）、过程证据（记忆增长、规则更新、版本历史）。

---

## 范围边界

| 本项目做 | 本项目不做 |
|---|---|
| 影像质控与征象描述 | 签发诊断报告 |
| 疑似疾病排序与依据 | 下最终诊断结论 |
| 分级/分期建议（ICDR 等） | 治疗方案制定 |
| 复查与转诊建议（延伸） | 用药与剂量建议 |
