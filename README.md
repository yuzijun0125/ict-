# 眼底影像辅助诊断可进化智能体

> 第十一届华为 ICT 大赛 · 创新赛 · 赛题 3
> 基于华为 ModelEngine / Nexent，面向西医眼科的眼底影像辅助诊断与医生问答智能体

## 项目一句话

把眼底影像、病历、检查、检验和既往随访资料组织成一条可追溯的诊断证据链，辅助医生识别病灶、形成疑似疾病排序和鉴别诊断，并支持医学依据可核验的连续追问。

**系统只提供辅助诊断意见，最终诊断和医疗决策由执业医师作出。**

---

## 核心能力

| 能力 | 说明 |
|---|---|
| 多模态资料接入 | CFP、超广角、OCT、OCTA、FFA、B 超，以及 PDF/图片病历、检查报告和检验资料 |
| 影像质量控制 | 检查清晰度、曝光、遮挡、视野、伪影和可判读性，不合格时提示重拍或拒答 |
| 病灶识别与量化 | 定位微动脉瘤、出血、渗出、棉絮斑、玻璃膜疣、水肿、新生血管等病灶 |
| 病历与检验分析 | 提取病史、危险因素、眼科检查、实验室指标、时间线和信息缺口 |
| 多模态病例融合 | 将影像、病历、检验、既往治疗和随访变化统一到同一病例上下文 |
| 疑似疾病与分级 | 输出 Top-N 候选疾病、支持/反对证据、鉴别要点和分级/分期建议 |
| 完整知识库 | 覆盖疾病、影像、病历、检验、诊断标准、鉴别、急症、随访和安全规则 |
| 医生连续问答 | 回答“为什么这样判断、还需排除什么、缺哪些检查、与上次相比是否进展”等问题 |
| 可追溯引用 | 关键医学声明绑定指南名称、版本、条款或 DOI 及病例原始证据 |
| 安全进化 | 医生确认/修正经专家审核后用于检索、排序、规则和模型的受控迭代 |

## 系统闭环

```text
眼底影像 + 病历 + 检验 + 既往随访
                ↓
        脱敏、质控与结构化
                ↓
     影像分析与病历时间线并行
                ↓
         多模态病例融合
                ↓
    疑似疾病排序 + 分级 + 鉴别
                ↓
      证据检索与引用核验
                ↓
  结构化报告 + 医生连续问答
                ↓
      医生复核与反馈
                ↓
    审核、回归、灰度与回滚
```

## 项目范围

### 首批重点方向

糖尿病视网膜病变、糖尿病黄斑水肿、年龄相关性黄斑变性、视网膜静脉阻塞、青光眼性视神经损害。

### 扩展方向

病理性近视、视网膜裂孔/脱离、黄斑前膜、黄斑裂孔、中心性浆液性脉络膜视网膜病变等。

### 明确不做

- 不下最终诊断；
- 不开发方、剂量、疗程或药物选择；
- 不决定激光、手术或其他治疗方案；
- 不替代医生面诊、会诊和随访；
- 未经注册不得用于临床独立诊疗决策。

## 知识库范围

知识库围绕西医眼科构建，包含：

1. 解剖与生理；
2. 疾病定义、危险因素、症状和并发症；
3. 眼底影像采集、征象和量化规范；
4. 诊断标准、分级与分期规则；
5. 鉴别诊断矩阵；
6. 病历、眼科检查和实验室检验字段；
7. 随访、转诊与急症路径；
8. 安全、隐私、合规与拒答规则；
9. 经审核的典型和边界病例。

每条知识需记录来源、发布机构、版本、生效时间、适用人群和更新状态。知识更新经过医学专家审核、检索评测、版本登记与回滚管理。

## 技术框架

- 智能体平台：ModelEngine / Nexent；
- 影像能力：质控、检测、分割、量化、纵向比较和 VLM；
- 文本能力：OCR、文档解析、病历结构化、单位归一化和时间线；
- 推理能力：多模态融合、候选疾病排序、概率校准和规则引擎；
- 知识能力：关键词 + 向量 + 知识图谱混合检索；
- 交互能力：病例工作台、报告编辑、医生连续问答和反馈；
- 治理能力：脱敏、权限、审计、版本、回归测试和灰度发布。
