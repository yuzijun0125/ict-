## 1. 项目概述

**项目名称（建议）**：眼底慧诊（FundusGuard）

**一句话定位**：
把"该不该转诊、多久复查、转到哪一级"这个基层眼科最常见、最容易做错的决策，交给一个能从复核结果中不断自我修正的智能体。

**项目边界声明（重要）**：
本项目定位为**辅助决策支持系统**，不提供疾病诊断结论与治疗处方，不替代医师执业行为；最终医疗决策由执业医师作出。所有输出附免责声明与依据来源。

## 2. 背景与痛点分析

### 2.1 疾病背景

眼底疾病是我国主要的不可逆致盲原因，具有**早期无症状、晚期不可逆、定期筛查可显著降低致盲率**的共同特点。

| 疾病 | 特点 | 决策相关性 |
|---|---|---|
| 糖尿病视网膜病变（DR） | 糖尿病患者主要致盲原因，患病基数大 | 筛查分级、随访间隔、转诊时机 |
| 糖尿病黄斑水肿（DME） | 视力损害主要因素 | 转诊紧急度 |
| 年龄相关性黄斑变性（AMD） | 老年致盲主因 | 复查频率、是否转专科 |
| 视网膜静脉阻塞（RVO） | 突发视力下降 | 紧急转诊判断 |
| 青光眼性视神经损害 | 不可逆、需长期随访 | 随访依从性 |
| 病理性近视眼底病变 | 年轻化 | 定期筛查决策 |
| 视网膜脱离 | 眼科急症 | 急诊升级决策 |

### 2.2 医疗痛点

1. **基层读片能力不足** —— 全科/基层医生缺乏眼底影像判读训练，漏诊、误诊率高
2. **专家资源分布不均** —— 优质眼科集中在大医院，基层"看不出、不敢转、不会转"
3. **转诊决策无标准路径** —— 该转的不转（延误），不该转的乱转（挤占资源）
4. **慢病随访失访率高** —— DR 患者需长期定期复查，实际按时复查率低
5. **经验难以沉淀** —— 个体医生的判断经验无法结构化复用

### 2.3 为什么选"决策"而不是"诊断"

| 维度 | 诊断类 | 决策/流程类（本项目） |
|---|---|---|
| 合规性 | 属医师执业行为，AI 产品按医疗器械管理 | 属辅助管理/流程建议，风险可控 |
| 反馈可得性 | 需病理/长期随访金标准，难获取 | 复核结果、实际就诊、复查变化，易获取 |
| 与赛题契合 | 偏"识别能力" | 正对"决策 + 可进化" |

## 3. 项目目标与范围

### 3.1 总目标

构建面向眼底疾病的辅助决策智能体，在基层筛查场景下给出**可解释、可追溯、可进化**的转诊与随访决策。

### 3.2 分目标

1. **决策能力**：输出风险分级、转诊建议、紧急程度、随访间隔、判断依据
2. **进化能力**：基于临床反馈自动沉淀经验，决策指标随反馈累积而提升
3. **安全能力**：安全护栏拦截越界输出（诊断、用药、安慰性否定）
4. **可解释性**：每条决策可追溯到指南条目或历史案例
5. **可演示性**：全流程现场可演示，决策改善可量化

### 3.3 范围边界

| 本项目做 | 本项目不做 |
|---|---|
| 转诊必要性判断 | 疾病确诊 |
| 紧急程度分级 | 治疗方案制定 |
| 随访间隔建议 | 用药与剂量建议 |
| 分级诊疗路径建议 | 手术指征判定 |
| 影像特征描述（非诊断性） | 影像诊断报告签发 |

## 4. 功能设计

### F1 眼底风险筛查与信息采集（多模态输入）

- **输入**：眼底彩色照相（CFP）、OCT/OCTA（可选）、结构化临床数据（年龄、糖尿病病程、HbA1c、血压、视力、眼压、主诉）
- **输出**：风险等级（无需转诊 / 建议复查 / 建议转诊 / 紧急转诊）+ 影像特征描述（如微动脉瘤、出血点、硬性渗出、新生血管等描述性词汇，不作诊断）
- **图像质控**：模糊、曝光不足、伪影等不可判读图像直接返回"建议重拍"，不进入决策

### F2 转诊决策

- 输出：是否转诊 / 紧急程度 / 建议科室或医院层级 / 判断依据 / 免责声明
- 规则：识别急症指征（突发视力下降、视网膜脱离征象、玻璃体积血等）必须升级为"立即转诊"

### F3 随访间隔决策

- 输出：下次复查建议时间（3 / 6 / 12 个月）及理由
- 依据：风险等级、血糖控制情况、既往依从性、年龄等

### F4 分级诊疗路径决策

- 输出路径：基层随访管理 → 二级医院眼科 → 三级医院眼底专科 → 急诊

### F5 反馈采集与进化（核心差异化功能）

- **采集**：上级医院复核结果、医生采纳/否决及原因、实际复查结果与病情进展
- **沉淀**：写入短期记忆（个案经验）+ 更新知识库（规则修正）
- **评估**：定期运行评测集，输出指标，形成版本迭代

### F6 安全护栏

- 拦截：确诊式表述（"你得了…"）、用药建议（药名/剂量）、安慰性否定（"不用去医院"）
- 命中后动作：替换为规范话术 + 建议线下就医

### F7 决策解释与可追溯

- 每条决策展示依据来源（指南名称/条款、知识库文档、相似历史案例）

### F8 随访提醒与依从性管理（进阶功能）

- 自动生成随访提醒计划，追踪复查完成情况

## 5. 决策与进化机制

### 5.1 决策链

```
输入（影像 + 临床数据）
   → 图像质控 → 特征描述提取
   → 知识库检索（指南依据）
   → 记忆检索（相似历史案例与个体偏好）
   → 规则推理（分级 + 急症升级）
   → 决策输出（分级 / 转诊建议 / 随访间隔 / 依据 / 免责声明）
```

### 5.2 进化闭环（本项目的灵魂）

```
        决策输出
           │
           ▼
   临床反馈：复核结果 / 医生采纳与否 / 复查进展
           │
     ┌─────┴─────┐
     ▼           ▼
 记忆沉淀     知识库修正
 （个案经验） （规则/边界完善）
     └─────┬─────┘
           ▼
   评估器计算指标（敏感度 / 特异度 / Kappa / 命中率）
           │
           ▼
   版本迭代 v1 → v2 → v3（指标提升可量化）
```

### 5.3 三层记忆的使用设计

| 层级 | 内容 | 作用 |
|---|---|---|
| Tenant 记忆 | 转诊规则、分级口径、合规红线、急症指征 | 统一决策标准 |
| User 记忆 | 患者个体情况、依从性、既往病史概要 | 个体化决策 |
| Agent 记忆 | 被纠正的案例、边界情况、失败反思 | 越用越准 |

### 5.4 可量化指标

| 维度 | 指标 |
|---|---|
| 转诊必要性判断 | 敏感度、特异度、AUC、漏转率 |
| 风险分级一致性 | 与专家金标准的 Kappa 系数 |
| 随访间隔建议 | 命中率、平均偏差（月） |
| 进化效果 | v1 → v2 各指标提升幅度 |
| 安全性 | 越界输出拦截率（护栏测试） |
| 效率 | 单例决策耗时、医生采纳率 |

## 6. 计算机技术方案讨论

### 6.1 多模态感知层

- **图像预处理**：去噪、光照不均校正、ROI 裁剪、视盘/黄斑定位、血管分割
- **图像质控**：模糊度、曝光、伪影检测 → 不可判读图直接拒识（保证决策输入质量）
- **视觉语言模型（VLM）**：输出结构化影像描述，仅描述可见征象，不下诊断结论
- **多源融合**：影像特征 + 结构化临床表格 + 主诉文本

### 6.2 知识与检索层（RAG）

- 知识库内容：诊疗指南、分级标准、转诊共识、科室能力清单、急症指征表
- 检索策略：向量检索 + 关键词混合召回，返回带来源的片段
- 可追溯：输出引用具体文档与条款，支撑可解释性

### 6.3 推理与决策层

- LLM 承担规则推理与决策表达
- 工具调用：知识库检索、记忆检索/写入、结构化数据查询
- **输出强约束**：固定 JSON Schema（风险等级、转诊建议、紧急度、随访间隔、依据、免责声明），便于评估与审计

### 6.4 记忆与进化层

- 短期记忆自动归纳（反馈、纠错、进展）
- 长期记忆版本化管理（Tenant / User）
- 定期整理（去重、淘汰过期、冲突消解）

### 6.5 评估与治理层

- 评测集构建（含专家金标准）
- 指标计算、回归测试、新旧版本 A/B 对比
- 版本管理（可回滚）
- 安全护栏（内容匹配规则）+ 人工抽检

### 6.6 工程与集成层

- 容器化部署，保证演示环境可复现
- MCP 工具接入：演示阶段以模拟 HIS/PACS 接口为主（真实院内系统需审批）
- 数据脱敏与访问控制
- 全链路日志审计（决策可回溯）

### 6.7 技术选型建议

| 环节 | 候选方案 | 选型考虑 |
|---|---|---|
| 决策大模型 | DeepSeek 系列 / Qwen 系列 | 中文医学语境表现、成本 |
| 视觉模型 | Qwen-VL / InternVL / 商用多模态 | 眼底影像特征描述能力需实测 |
| 向量模型 | BGE-M3 / text-embedding-v3 | 中文医学文本检索效果 |
| 智能体平台 | ModelEngine / Nexent | 赛题要求 + 记忆/知识库/护栏原生支持 |
| 后端 | FastAPI + PostgreSQL + 向量库 | 结构化与检索并重 |

## 7. 医疗价值（解决什么问题）

| 医疗问题 | 本项目的缓解方式 | 可量化指标 |
|---|---|---|
| 基层漏诊、延误 | 风险分级 + 转诊提醒 | 筛查敏感度、漏转率 |
| 专家资源分布不均 | 分层分流，轻症基层随访 | 三级医院非必要转诊占比 |
| 转诊无序 | 路径决策 + 紧急度分级 | 转诊符合率 |
| 慢病随访失访 | 个体化随访间隔决策 + 提醒 | 按期复查率 |
| 决策不透明、医生不信任 | 依据可追溯 | 医生采纳率 |
| 经验难以沉淀 | 记忆 + 版本迭代 | 指标随反馈提升幅度 |
| 患者健康教育不足 | 规范话术 + 免责提示 | 满意度、复诊意愿 |

**社会价值**：助力分级诊疗落地，把优质眼科判断能力"下沉"到基层，降低可避免致盲。

**经济价值**：降低非必要转诊成本与晚期治疗成本，具备向基层医疗机构、体检中心、慢病管理平台推广的潜力。

## 10. 风险与应对

| 风险 | 影响 | 应对措施 |

| 触碰"诊断"红线 | 合规风险、作品被质疑 | 明确定位辅助决策、护栏拦截、免责声明 |
