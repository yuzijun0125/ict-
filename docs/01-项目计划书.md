# 📌 一页看懂

| 你可能想问 | 回答 |
|---|---|
| **做什么？** | 一个帮医生把"**眼底片子**"和"**中医辨证**"打通的智能体 |
| **怎么用？** | 输入眼底影像 + 四诊信息 → 输出：①西医诊断分级 ②中医证型 ③**中西医结合方案建议** → 医生确认或修改 |
| **解决什么痛点？** | 中西医两套体系"**语言不通、人分两科、结合靠经验**" |
| **凭什么叫"可进化"？** | 中医师和西医的每次修改都被记住，**"影像—证型—方案"的映射越用越准** |
| **绝对不做什么？** | 不下诊断、不开处方、不定剂量、不替代医生 |

**一句话总结**：
> 做一个**中西医之间的"翻译器 + 协调器"**——让眼底影像能被中医读懂，让中医辨证能被眼科医生用上，最终给出**可解释、可追溯、可进化**的中西医结合方案建议。

# 一、痛点：中西医为什么"难以结合"

这是本项目的立项根基，也是最大的创新空间。

| 痛点 | 具体表现 |
|---|---|
| **① 语言不通** | 西医说"视网膜点片状出血、硬性渗出、ICDR 分级"；中医说"气阴两虚、血瘀阻络"。**两套术语体系之间没有标准对应关系** |
| **② 人分两科** | 眼科医生看得懂眼底片子，但不懂辨证；中医师会辨证，但**看不懂眼底影像** |
| **③ 结合靠经验** | "眼底出血多 → 该用活血化瘀"这类经验只在老医生脑子里，**没有结构化的知识载体** |
| **④ 方案各自为政** | 西医方案（抗 VEGF、激光、控糖）与中医方案（中药、针灸、中成药）**谁先谁后、如何协同，缺统一依据** |
| **⑤ 疗效评价不统一** | 西医看 BCVA（最佳矫正视力）、CMT（黄斑中心厚度）；中医看证候积分。**两套尺子难对齐** |
| **⑥ 证据等级不同** | 西医重 RCT，中医重辨证论治与真实世界经验，**证据难以合并成统一推荐** |

**核心矛盾一句话**：
> 中西医各自的诊疗逻辑都很完整，但**缺少一个能在两者之间"翻译"和"协调"的中间层**。

## 我们的破题思路

**把"中间层"做成一个智能体。**

```
       西医知识                    中医知识
   （影像/分级/指南）          （四诊/证型/方药）
            \                    /
             \                  /
              ▼                ▼
        ┌─────────────────────────────┐
        │   中西医结合映射引擎（★核心）  │
        │  ① 影像征象 ↔ 疾病分级         │
        │  ② 四诊信息 ↔ 中医证型         │
        │  ③ 征象 ↔ 证型 ↔ 方案（关键）  │
        └──────────────┬──────────────┘
                       ▼
              中西医结合方案建议
                       ▼
                  医生复核确认
                       ▼
                    反馈进化
```

# 二、这个智能体具体做什么

## 2.1 输入

| 输入项 | 示例 | 是否必需 |
|---|---|---|
| **眼底影像** | 彩色眼底照相（CFP）；可选 OCT/OCTA | ✅ 必需 |
| **西医临床信息** | 年龄、糖尿病病程、HbA1c、血压、BCVA、眼压 | 建议 |
| **中医四诊信息** | 主诉、全身症状、舌象、脉象 | ✅ 必需（中医维度） |
| 舌象照片 | 可选 | 可选 |

> 💡 关键设计：**四诊信息即使是文本录入也能工作**——这让系统在基层（没有中医四诊仪）也能用。

## 2.2 输出（三段式，一眼看懂）

```
【第一段 · 西医维度】
  影像所见：双眼后极部散在点片状出血，4 个象限分布；颞侧多个微动脉瘤；
            黄斑区硬性渗出呈环形；静脉局部串珠样改变
  分级建议：糖尿病视网膜病变（重度非增殖期，ICDR 分级）
            合并糖尿病黄斑水肿（需 OCT 确认）
  依据来源：《我国糖尿病视网膜病变临床诊疗指南（2022年）》

【第二段 · 中医维度】
  四诊摘要：口干多饮、乏力、腰膝酸软、视物模糊；舌暗红少苔，脉细涩
  证型建议：气阴两虚兼血瘀阻络（主证 / 兼证分列）
  依据来源：《中医眼科学》教材、糖尿病视网膜病变中医诊疗共识

【第三段 · 中西医结合方案建议】★核心输出
  推荐策略：西医为主控制病情进展 + 中医辅助改善症状与微循环

  方案要素（按推荐顺序）：
   ① 【西医·基础】严格控制血糖、血压、血脂 —— 所有阶段的共同基础
      依据：DR 指南（2022）核心推荐
   ② 【西医·针对性】根据分级决定随访/转诊/专科治疗路径
      依据：ICDR 分级 + 分级诊疗服务技术方案
   ③ 【中医·辅助】辨证为气阴两虚兼血瘀 → 益气养阴、活血化瘀治法方向
      依据：中医药治疗 DR 研究进展；中成药循证研究（如芪明颗粒等）
   ④ 【协同要点】中医药作为辅助手段，不替代抗 VEGF/激光等必要的西医治疗
   ⑤ 【随访建议】复查间隔 3/6/12 个月 + 中医证候变化需同步记录

  ⚠️ 本建议仅为方案思路参考，不含具体处方与剂量；
     中西医结合用药须由具备资质的医师根据患者具体情况决定。
```

> 📌 注意：**输出的是"方案要素与策略"，不是"处方"**。这是合规底线，也是能落地的关键。

## 2.3 它解决的三个关键问题

| 问题 | 本系统怎么解决 |
|---|---|
| 中医看不懂眼底片子 | 把 **影像征象翻译成中医能理解的语言**（如"出血多、色鲜红 → 提示血热妄行/络伤出血"） |
| 西医不懂辨证 | 把 **四诊信息结构化为证型建议**，并说明与影像征象的关联 |
| 结合靠经验、无法传承 | 把"**征象—证型—方案**"的对应关系**固化成可检索、可验证、可迭代的知识资产** |

# 三、核心创新：三张映射表

这是本项目最硬的原创贡献，也是知识库的核心资产。

| 映射表 | 作用 | 举例 |
|---|---|---|
| **① 影像征象 ↔ 疾病分级** | 西医侧推理 | "4 象限出血 + 静脉串珠" → 重度 NPDR |
| **② 四诊信息 ↔ 中医证型** | 中医侧推理 | "口干多饮 + 乏力 + 舌暗红少苔 + 脉细涩" → 气阴两虚兼血瘀 |
| **③ 征象 ↔ 证型 ↔ 方案**（★核心） | **中西医结合推理** | "微血管瘤 + 点状出血 + 病程长 → 气阴两虚、血瘀阻络 → 益气养阴 + 活血化瘀，作为西医治疗辅助" |

**第三张表就是"中西医结合的中间层"**——它把过去只存在于医生经验中的对应关系，变成了机器可推理、可解释、可被医生修正的结构化知识。

# 四、系统怎么运转

## 4.1 全流程图

```
患者眼底影像 + 四诊信息
        │
        ├─►【① 影像质控】照片清不清楚？不清楚→建议重拍
        │
        ├─►【② 西医分析】征象描述 → 疾病分级建议
        │
        ├─►【③ 中医分析】四诊结构化 → 证型建议
        │
        ├─►【④ 映射引擎】★ 征象 ↔ 证型 建立关联
        │
        ├─►【⑤ 方案生成】中西医结合策略 + 排序 + 依据
        │
        └─►【⑥ 安全护栏】拦截处方/剂量/绝对化表述
                        │
                        ▼
                医生复核：采纳 / 修改 / 否决
                        │
                        ▼
        反馈入库 → 映射关系修正 + 方案排序优化 → 版本迭代
```

## 4.2 每一步在做什么

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| ① 影像质控 | 判断照片能不能看清 | 看不清硬分析只会出错 |
| ② 西医分析 | 只描述征象 + 给分级建议 | 客观、可核对、不越权 |
| ③ 中医分析 | 四诊信息 → 证型建议 | 让中医逻辑显性化 |
| ④ **映射引擎** | **把两套语言对上** | ★ 这是解决"难以结合"的关键 |
| ⑤ 方案生成 | 西医为主 + 中医辅助 + 协同要点 | 给出可执行的策略而非处方 |
| ⑥ 安全护栏 | 拦截越界表述 | 合规底线 |
| ⑦ 医生复核 | 中医师 + 西医都能改 | 反馈是进化的燃料 |

# 五、"可进化"怎么实现（重点）

## 5.1 一个比喻

> 就像**中西医双师带教**：第一次智能体把"眼底出血"对应成"血热妄行"，中医师说"不对，这位患者是气虚不摄血"；智能体记住了。下次遇到类似征象组合，它就会同时考虑这两种可能。

## 5.2 三个反馈来源（本项目的独特之处）

| 反馈来源 | 修正什么 |
|---|---|
| **西医医生** | 西医分级、转诊判断 |
| **中医师** | 证型辨识、治法方向 |
| **中西医结合医生** | **映射关系本身**（"这类征象其实更常对应这个证型"） |

> 三种角色的反馈共同训练同一个映射引擎——这是"中西医结合"真正落到实处的技术体现。

## 5.3 进化的三类证据

| 证据 | 展示方式 |
|---|---|
| **行为证据** | 同一病例，反馈后再问，方案更接近医生判断 |
| **数据证据** | 证型辨识准确率、方案采纳率、Kappa 一致性从 v1 到 v2 提升 |
| **过程证据** | 映射表条目增长、规则修正记录、版本迭代历史 |

# 七、技术方案（大白话版）

## 7.1 系统由哪几块组成

| 模块 | 作用 | 通俗理解 |
|---|---|---|
| **看图模块** | 把眼底照片变成文字描述 | 智能体的"眼睛" |
| **辨证模块** | 把四诊信息变成证型判断 | 智能体的"中医思维" |
| **映射模块** ★ | 建立影像与证型的对应 | 智能体的"中西医翻译器" |
| **知识模块** | 存三套知识（西医 / 中医 / 结合） | 智能体的"三本教科书" |
| **方案模块** | 综合生成结合方案 | 智能体的"会诊能力" |
| **记忆模块** | 记住医生的每次修改 | 智能体的"临床经验" |
| **界面与反馈** | 医生看结果、点采纳 | 实际使用的地方 |

## 7.2 关键技术

| 技术 | 用在哪 | 说明 |
|---|---|---|
| **视觉语言模型（VLM）** | 看眼底影像 | 输出结构化征象描述 |
| **大语言模型（LLM）** | 中医辨证推理 | 处理四诊文本，输出证型建议 |
| **知识库检索（RAG）** | 查依据 | 从三套知识库检索对应条款 |
| **结构化映射表** ★ | 中西医结合 | 三张映射表作为推理主干 |
| **记忆机制** | 记住反馈 | 三层记忆（租户/用户/智能体） |
| **安全护栏** | 合规 | 规则拦截越界表述 |
| **评测指标** | 证明效果 | 准确率、一致性、采纳率 |

## 7.3 输出结构（强制 Schema）

```json
{
  "imaging":  { "quality": "...", "findings": [...], "grade_suggestion": "..." },
  "tcm":      { "four_diagnoses": {...}, "syndrome": [...], "rationale": "..." },
  "mapping":  { "finding_syndrome_links": [...] },
  "plan":     { "strategy": "...", "elements": [...], "sequence": [...] },
  "evidence": [ { "claim": "...", "source": "..." } ],
  "disclaimer": "..."
}
```

固定结构的好处：**可评估、可审计、方便医生逐项核对与修改**。

# 八、能带来什么价值

## 8.1 对医生

| 角色 | 价值 |
|---|---|
| 眼科医生 | 不用懂中医，也能看到**辨证建议与中医辅助思路** |
| 中医师 | 不用会看眼底片，也能看到**影像征象与分级** |
| 中西医结合医生 | 从"凭经验"变成**有依据、可复核、可积累** |

## 8.2 对患者

- 中西医方案**协同而非各行其是**，减少重复与冲突
- 慢病（如糖尿病视网膜病变）长期管理中，**中医调理与西医控病同步推进**

## 8.3 对学科

> **把"中西医结合"从个人经验，变成可复用、可验证、可传承的结构化知识资产。**

这是本项目的最大价值——它不只是做工具，而是**在沉淀一套方法论**。

## 8.4 可量化指标

| 指标 | 含义 |
|---|---|
| 西医分级一致性（Kappa） | 与眼科医生判断的一致程度 |
| 证型辨识准确率 | 与中医师辨证的一致程度 |
| **方案采纳率** ★ | 医生直接采用建议的比例（越用越高=进化） |
| 映射表覆盖率 | 已建立对应关系的征象—证型组合比例 |
| 单例耗时 | 生成一份结合方案所需时间 |

# 十一、风险与应对

| 风险 | 应对 |
|---|---|
| 映射关系缺乏权威依据 | 优先引用中西医结合共识；无法溯源的关系标注为"经验性，待验证" |
| 中医证型判定争议大 | 输出多证型并排序 + 说明依据；由中医师最终判定 |
| 被认为在"开处方" | 严禁输出方剂组成/剂量；只给治法方向与方案要素 |
| 中西医结论冲突 | **不掩盖冲突**，明确呈现"西医角度建议…；中医角度建议…；协同要点…" |
| 中医数据难获取 | 用公开医案 + 专家构造的模拟数据；真实数据须伦理审查 |
| 评委质疑"结合是否真实" | 用**映射表 + 三方反馈 + 采纳率提升**三重证据证明 |

## 三条不能破的底线

1. **只给方案思路，不给处方剂量**
2. **必须标注依据来源与证据等级**（中医内容尤其要说明是循证还是经验）
3. **医生必须在环**——中医师与西医共同确认
