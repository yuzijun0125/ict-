## 七、引用规范建议

1. 中文期刊：作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
2. 指南：标注**发布机构 + 版本年份**
3. 国际指南：标注**版本号与更新日期**
4. 所有入库资料登记：**来源、获取日期、版本**，便于复核与更新
