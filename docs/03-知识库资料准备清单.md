## 五、资料整理规范

1. **统一命名**：`疾病_资料类型_版本年份`，如 `DR_诊疗指南_2023`
2. **保留出处**：每条资料记录发布机构、期刊、DOI/链接、版本年份
3. **切分粒度**：按"一个知识点一个片段"切分，便于检索命中和溯源
4. **脱敏处理**：
   - 去除患者姓名、身份证号、联系方式、住院号、影像 DICOM 中的个人信息
   - 影像去除可识别标记（如检查号、日期水印）
5. **版本管理**：指南更新时保留旧版并标注生效区间，避免历史决策依据丢失
6. **禁止入库内容**：真实患者可识别信息、未授权数据、来源不明资料

## 六、知识库验收标准

| 检查项 | 标准 |
|---|---|
| 覆盖度 | P0 资料齐全，涵盖 5 类主要眼底疾病 |
| 可溯源 | 每条检索结果能定位到来源文档与条款 |
| 一致性 | 不同来源冲突时以最新权威指南为准，并记录裁决理由 |
| 时效性 | 指南版本在有效期内，标注更新提醒 |
| 合规性 | 无患者隐私信息，全部资料有明确来源与授权 |
| 检索质量 | 典型问题 Top-3 召回率 ≥ 90%（自测） |
