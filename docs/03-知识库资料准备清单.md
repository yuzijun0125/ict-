# 知识库资料准备清单（眼底影像辅助诊断方向）

> 本清单用于配置 Nexent 知识库，支撑"**影像征象识别 → 疑似疾病推理 → 分级建议**"的可溯源输出。
> 每条资料需登记：**来源、发布机构、版本/年份、获取日期、是否脱敏**。

## 二、决策规则资料（P0：必须整理成结构化表格）

> 这是知识库的**核心资产**：不仅供检索，也直接驱动推理。

### 2.1 征象-疾病映射表（★最重要）

| 字段 | 说明 | 示例 |
|---|---|---|
| 征象组合 | 一个或多个影像征象 | 微动脉瘤 + 点片状出血 |
| 关联疾病 | 可能的疾病 | 糖尿病视网膜病变（非增殖期） |
| 支持强度 | 强/中/弱 | 强 |
| 需鉴别疾病 | 易混淆疾病 | 视网膜静脉阻塞 |
| 鉴别要点 | 区分依据 | 出血分布是否沿血管、是否单侧 |
| 出处 | 指南/文献 | 《我国DR临床诊疗指南》 |

### 2.2 其他规则表

| 表格 | 字段 | 用途 |
|---|---|---|
| 征象术语表 | 中文名、英文名、定义、影像特征、典型图例 | 描述标准化 |
| 分级标准表 | 疾病、分级、判定条件、依据条目 | 分级建议 |
| 鉴别诊断表 | 疾病A、疾病B、区分征象、易错点 | 减少误判 |
| 急症征象表 | 征象、紧急度、建议动作、提示语 | 急症提示 |
| 影像质控表 | 质控项、合格阈值、不合格处理 | 拒识规则 |
| 免责话术库 | 场景、规范话术 | 表述合规 |

## 三、数据资料

### 3.1 公开影像数据集（详见 02 文档）

| 数据集 | 特点 | 是否含征象级标注 |
|---|---|---|
| Kaggle DR（EyePACS） | 量大，DR 0-4 级 | 否（仅图像级） |
| APTOS 2019 | DR 分级 | 否 |
| Messidor-2 | DR 分级 + 黄斑水肿 | 否 |
| **IDRiD** | **含微动脉瘤、出血、硬性渗出等像素级标注** | ✅ 是 |
| DDR | 大规模 DR 分级 | 否 |
| OIA-ODIR | 多疾病分类（含青光眼、白内障等） | 否 |

| REFUGE | 青光眼视盘/视杯分割 | 分割标注 |

> 建议组合：**IDRiD（征象级）+ RFMiD/OIA-ODIR（多疾病）** 覆盖"征象→疾病"链路。

| 要求 | 说明 |
|---|---|
| 规模 | 建议 ≥100 例，覆盖各疾病与各分级 |
| 金标准 | **眼科医师独立给出的诊断与分级结论** |
| 覆盖 | 正常 / DR（各期）/ DME / AMD / RVO / 青光眼 / 其他 |

| 用途 | v1 基线 → 反馈迭代 → v2 回归对比 |

## 四、资料整理规范

1. **统一命名**：`疾病_资料类型_版本年份`（如 `DR_诊疗指南_2023`）
2. **保留出处**：发布机构、期刊、DOI/链接、版本年份
3. **切分粒度**：一个知识点一个片段（"征象→疾病→依据"三位一体）
4. **图文配套**：征象条目尽量附**典型图例**，提升检索与理解效果
5. **脱敏处理**：
   - 影像去除患者信息、检查号、日期水印等可识别标记
   - 删除 DICOM 头中的患者隐私字段
6. **版本管理**：指南更新时保留旧版并标注生效区间
7. **禁止入库**：真实患者可识别信息、未授权数据、来源不明资料

## 五、知识库验收标准

| 检查项 | 标准 |
|---|---|
| 覆盖度 | P0 资料齐全，覆盖 ≥5 类主要眼底疾病 |
| 核心表完整 | 征象术语表、征象-疾病映射表、分级标准表、鉴别诊断表四表齐备 |
| 可溯源 | 每条检索结果可定位到来源文档与条款 |
| 冲突处理 | 不同来源冲突以最新权威指南为准，并记录裁决理由 |
| 时效性 | 指南版本在有效期内，有更新提醒机制 |
| 合规性 | 无患者隐私信息，全部资料有明确来源 |
| 检索质量 | 典型"征象→疾病"查询 Top-3 召回率 ≥ 90%（自测） |

## 六、配置顺序建议

```
① 收集中文指南（P0）
      ↓
② 整理四张核心表（征象术语 / 征象-疾病映射 / 分级标准 / 鉴别诊断）
      ↓
③ 影像与文本脱敏、按知识点切分
      ↓
④ 导入知识库 + 配置检索
      ↓
⑤ 用典型征象查询自测召回质量
      ↓
⑥ 补充 OCT/OCTA 与扩展疾病资料（P1）
```
