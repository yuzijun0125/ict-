# 项目资料准备总清单（西医眼底影像辅助诊断）

> 本文回答三个问题：**需要收集什么、需要阅读哪些论文、自己必须创建什么。**
> 适用范围：DR、DME、AMD、RVO、青光眼性视神经损害等 P0 眼底疾病。
> 更新日期：2026-09-25

---

## 0. 先看结论：最低准备包

如果时间有限，至少完成以下内容，项目才具备完整演示基础：

| 优先级 | 必须准备 | 最低建议 |
|---|---|---|
| P0 | 合规与伦理资料 | 法规清单、数据授权、伦理材料、脱敏规范、免责声明 |
| P0 | 诊疗指南与标准 | 5 个 P0 疾病各有诊断、分级、鉴别、转诊和随访依据 |
| P0 | 论文池 | 核心论文 40–60 篇；正式引用库 100–150 篇 |
| P0 | 公开数据集与数据说明 | 至少覆盖 DR、DME、AMD、RVO、青光眼及病灶标注 |
| P0 | 疾病知识卡 | 5 个 P0 疾病各 1 份 |
| P0 | 影像征象表 | 30–50 个核心征象，中英文、定义、图例、疾病关联齐全 |
| P0 | 病历/检验字段字典 | 80–120 个字段，含单位、参考区间、缺失值和冲突规则 |
| P0 | 诊断分级/鉴别规则 | 5 套分级规则 + 10–20 组鉴别关系 |
| P0 | 安全规则 | 越界提问、急症、证据不足、低质量影像和隐私规则 |
| P0 | 评测集 | 每病种建议 ≥100 例；竞赛早期可先用 20–30 例做基线 |
| P0 | Agent 输出规范 | JSON Schema、问答结构、引用格式和拒答模板 |
| P1 | 系统文档与演示 | 技术设计、部署说明、演示病例、PPT、视频和答辩材料 |

> 优先级说明：**P0 是没做完就无法可靠演示；P1 是影响完成度；P2 是后续扩展。**

### 2.3 每篇论文需要提取什么

不要只保存 PDF，至少建立以下文献卡：

| 字段 | 说明 |
|---|---|
| 题名/作者/期刊/年份 | 标准引用信息 |
| DOI/链接 | 可核验来源 |
| 研究类型 | 指南、RCT、Meta、回顾性、前瞻性等 |
| 研究对象 | 人群、病种、模态、医院和样本量 |
| 核心结论 | 一句话说清 |
| 可引用知识点 | 对应诊断、分级、模型或安全规则 |
| 指标 | AUC、敏感度、特异度、Kappa、QWK 等 |
| 局限 | 设备、人群、回顾性、样本偏差等 |
| 项目用途 | 知识库、算法、评测、方案还是答辩 |
| 引用位置 | 放入哪张知识表或哪一章节 |

**最终要形成：**《核心文献卡》《证据等级表》《引用索引》《论文到知识点的映射表》。

## 5. 按优先级准备顺序

### 第 1 周：合规、范围和指南

- 法规、伦理、授权和脱敏规范；
- 5 个 P0 疾病指南与分级标准；
- 项目范围、非目标和首批用户流程。

### 第 2 周：论文、知识卡和字段

- 建立 40–60 篇核心文献卡；
- 完成疾病卡、征象卡、诊断分级和鉴别矩阵初稿；
- 建立病历和检验字段字典。

### 第 3 周：数据和标注

- 下载并登记公开数据集；
- 完成数据划分、标注手册和质控规则；
- 启动金标准评测集和专家复核。

### 第 4 周：系统知识库与 Agent

- 完成知识切分、索引和版本登记；
- 建立工具接口、工作流和输出 Schema；
- 打通影像、病历、检验和时间轴。

### 第 5 周：评测与安全

- 完成疾病、分级、问答和引用评测；
- 建立越界、隐私、急症和低质量测试；
- 收集医生反馈并进行版本回归。

### 第 6 周：交付和答辩

- 技术文档、部署手册和用户手册；
- 演示病例、视频、PPT 和答辩问答；
- 与 `main` 分支同步最终版本。
