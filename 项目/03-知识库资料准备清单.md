# 知识库资料准备清单（西医眼底影像辅助诊断）

> 用途：支撑“影像征象识别 → 病历/检验融合 → 疑似疾病排序 → 分级与鉴别 → 医生连续问答”的可追溯辅助诊断流程。
> 原则：只收录西医眼科学、循证医学和可核验的诊断知识；每条资料登记来源、机构、版本、年份、适用范围和获取日期。

---

## 一、建设目标与边界

### 1.1 目标

建立覆盖影像、病历、检验、诊断、分级、鉴别、急症、随访和安全规则的西医眼科知识库，使每条医学结论都能追溯到原始证据。

### 1.2 “完整”的验收定义

1. 已承诺病种均具备疾病卡、诊断标准、分级规则、鉴别矩阵、急症和随访知识；
2. 眼影像、病史、眼科检查、实验室指标和纵向资料均有结构化字段；
3. 每条知识可定位到指南版本、条款、页码或 DOI；
4. 术语、缩写、同义词和上下位关系统一；
5. 具备知识更新、冲突裁决、版本对比和回滚机制；
6. 具备超范围、证据不足和急症场景的拒答/升级规则；
7. 覆盖度、检索召回、引用正确率和专家一致性可以量化验收。

## 二、疾病范围

### 2.1 P0 竞赛主范围

| 疾病 | 必备知识 |
|---|---|
| 糖尿病视网膜病变（DR） | 定义、危险因素、ICDR 分级、影像征象、转诊和随访 |
| 糖尿病黄斑水肿（DME） | OCT 标准、黄斑中心厚度、视网膜内液/下液、视力和治疗背景 |
| 年龄相关性黄斑变性（AMD） | 玻璃膜疣、色素改变、地图样萎缩、CNV、OCT/OCTA 和分期 |
| 视网膜静脉阻塞（RVO） | 分型、出血分布、静脉异常、缺血评估、黄斑水肿和危险因素 |
| 青光眼性视神经损害 | 视盘、杯盘比、盘沿、RNFL/GCC、眼压和视野 |

### 2.2 P1 扩展范围

病理性近视、视网膜裂孔/脱离、黄斑前膜、黄斑裂孔、中心性浆液性脉络膜视网膜病变、高血压性视网膜病变等。

### 2.3 P2 后续范围

其他视网膜、脉络膜、玻璃体、视神经和儿童眼底疾病。未纳入知识库范围的疾病必须显示“当前支持有限”，不得强行给出确定结论。

## 四、必须结构化的核心知识表

### 4.1 疾病知识卡

| 字段 | 说明 |
|---|---|
| 疾病名称 | 中文名、英文名、缩写、常用编码 |
| 定义与人群 | 定义、流行病学、典型年龄和适用人群 |
| 危险因素 | 局部和全身危险因素 |
| 症状与病史 | 典型主诉、病程和单/双眼特点 |
| 影像特征 | 模态、典型征象和分布 |
| 诊断标准 | 阳性条件、排除条件和必要检查 |
| 分级/分期 | 标准名称、等级条件和边界说明 |
| 鉴别疾病 | 相似疾病和关键区分点 |
| 并发症/急症 | 高风险改变和转诊条件 |
| 随访 | 复查间隔、进展指标和处理路径 |
| 证据来源 | 指南、版本、条款、DOI |
| 局限 | 不适用人群、证据不足点、常见误诊 |

### 4.2 影像征象卡

字段：中文名、英文名、缩写、定义、解剖区域、模态、图像特征、典型疾病、非典型情况、易混征象、严重程度阈值、标注规范、图例、反例、来源和版本。

### 4.3 征象—疾病—临床证据映射表

| 字段 | 说明 |
|---|---|
| 征象组合 | 微动脉瘤、出血、渗出、棉絮斑、水肿、新生血管等 |
| 临床/检验特征 | 糖尿病病程、HbA1c、血压、视力、眼压、治疗史等 |
| 候选疾病 | 可能疾病 |
| 支持强度 | 强/中/弱 |
| 支持证据 | 影像、病史、检验或随访依据 |
| 反对证据 | 降低可能性的条件 |
| 鉴别疾病 | 最易混淆疾病 |
| 关键区分点 | 最重要鉴别证据 |
| 缺失信息 | 提高置信度所需资料 |
| 来源与版本 | 指南/文献条款与生效版本 |

### 4.4 诊断与分级规则表

字段：疾病、标准体系、等级/分期、适用人群、阳性条件、排除条件、证据来源、版本、边界案例和规则冲突。

### 4.5 鉴别诊断矩阵

字段：疾病 A、疾病 B、相似征象、区分征象、支持检查、常见误判、影像/临床冲突和来源。

### 4.6 病历与检验字段字典

字段：标准字段名、中英文同义词、数据类型、单位、参考区间、必填性、缺失处理、异常定义、来源位置和时间属性。

### 4.7 随访、转诊与急症规则表

字段：触发条件、风险等级、建议动作、建议时限、依据、适用人群、禁止表述和人工复核要求。

### 4.8 安全与问答规则表

字段：风险场景、允许回答、禁止回答、必须引用内容、必须追问的信息、升级路径和标准话术。

### 5.2 自有/合作数据

- 真实临床影像、病历和检验需完成伦理审查、患者授权和脱敏；
- 评测集按患者级别划分，避免同一患者跨训练和测试；
- 每病种建议 ≥100 例，覆盖典型、边界、共病和低质量图像；
- 标注至少双人独立完成，分歧由高年资专家裁决；
- 评测集需包含外部机构、设备和人群数据。

### 5.3 评测指标

| 类别 | 指标 |
|---|---|
| 质控 | Accuracy、Sensitivity、Specificity、拒识率 |
| 病灶 | Precision、Recall、F1、mAP、Dice/IoU |
| 疾病 | Top-1/Top-3、AUROC、AUPRC、敏感度、特异度 |
| 分级 | Accuracy、QWK、±1 级一致率、Kappa |
| 校准 | ECE、Brier Score |
| 问答 | 事实正确率、证据一致率、引用正确率、拒答正确率 |
| 安全 | 越界拦截率、急症召回率、隐私事件数 |
| 效率 | 平均/P95 延迟、医生节省时间 |

## 六、资料整理规范

1. **命名统一**：使用“疾病_资料类型_版本年份”的格式。
2. **来源完整**：发布机构、期刊、DOI/链接、版本、生效日期和获取日期。
3. **切分粒度**：按“一个诊断知识点一个片段”切分，保留上下文和条款编号。
4. **图文配套**：征象条目尽量配置典型图例、反例和标注说明。
5. **单位统一**：检验和眼科检查必须保留原值、单位、参考区间和标准值。
6. **脱敏要求**：删除姓名、病案号、身份证号、日期水印、DICOM 患者字段和可识别文本。
7. **版本管理**：保留旧版、生效区间、变更原因和替换关系。
8. **禁止入库**：无来源内容、过期指南、未授权资料、患者可识别信息、模型自行生成的医学规则。

## 七、知识处理与检索

### 7.1 处理流程

```text
资料收集 → 版权/许可检查 → 解析 → 知识点切分
→ 专家审定 → 结构化标注 → 版本登记 → 索引构建
→ 检索测试 → 发布 → 使用监控 → 更新/回滚
```

### 7.2 索引结构

- 关系数据库：疾病、字段、版本、审核记录和病例关联；
- 向量索引：语义检索指南条款和知识片段；
- 关键词索引：医学专名、缩写、分级编号和数字阈值；
- 知识图谱：疾病—征象—检查—危险因素—鉴别—随访关系；
- 病例索引：经审核的相似病例和修正记录；
- 证据索引：每条医学声明的来源、条款和引用位置。

### 7.3 检索要求

- 查询需带疾病、模态、人群和版本约束；
- 同时执行关键词、向量和图谱检索；
- 返回支持证据和反对证据；
- 只使用现行、适用且授权范围内的知识；
- 证据不足时降低置信度或拒答；
- 关键声明必须显示引用来源。

## 八、知识库验收标准

| 检查项 | 标准 |
|---|---|
| 疾病覆盖 | P0 疾病全部具备完整知识卡和诊断分级规则 |
| 核心表完整 | 疾病卡、征象卡、映射表、分级表、鉴别矩阵、病历/检验字典、安全规则齐备 |
| 来源可追溯 | 每条知识可定位到原始来源和具体条款 |
| 时效性 | 现行指南比例达标，过期知识已隔离或替换 |
| 冲突处理 | 来源冲突完成裁决并保留理由 |
| 检索质量 | 典型问题 Top-3 证据召回率达到预设门槛 |
| 引用正确率 | 关键医学声明引用正确率 ≥95%（目标值） |
| 拒答能力 | 超范围、证据不足和越界请求能够正确拒答 |
| 数据合规 | 无患者隐私信息，授权和版本记录完整 |
| 医生复核 | 医学专家完成抽样审核并记录问题 |

## 九、配置顺序

```text
① 确定 P0 疾病和项目边界
        ↓
② 收集指南、共识、标准文献和影像规范
        ↓
③ 建立疾病卡、征象卡、诊断分级表、鉴别矩阵
        ↓
④ 建立病历、检验、随访、急症和安全规则
        ↓
⑤ 清洗公开数据集并准备患者级评测集
        ↓
⑥ 导入知识库并建立关键词/向量/图谱混合检索
        ↓
⑦ 使用典型和边界问题自测召回、引用和拒答
        ↓
⑧ 医学专家审核后发布 v1，建立更新与回滚机制
```
